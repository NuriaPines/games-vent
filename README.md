## 📖 Descripción

**Games Vent** es una aplicación web orientada a la gestión y exploración de videojuegos, diseñada siguiendo una arquitectura separada entre cliente y servidor.

El proyecto tiene como objetivo aplicar conceptos reales de desarrollo full-stack:

* Comunicación cliente-servidor
* Organización modular del código
* Consumo y gestión de datos
* Desarrollo web moderno

Este repositorio forma parte de un proyecto práctico enfocado al aprendizaje y consolidación de tecnologías web.

✅ Arquitectura frontend / backend

```bash
cd games-vent
```

---

### 2️⃣ Backend

```bash
# Colocar la carpeta backend en el servidor local
```

Ejecuta el servidor PHP.

---

### 3️⃣ Frontend

```bash

npm install
npm run dev
```
